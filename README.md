# ∂v/∂t

古い流体力学書の中で、`(v·∇)v`（ナビエ）だけが静かに自我を持ち、ページの外へ向かう短編タイポグラフィ映画です。遅れて目覚めた `ν(∇²)v`（ストークス）が、その軌跡を追います。

説明、開始画面、HUD、成功・失敗表示はありません。プレイヤーはナビエを直接ドラッグできます。流れと粘性、文字の密度、ストークスとの距離だけが手触りを変えます。操作しなくても物語はゆっくり進みます。

本文の流体力学上の説明は NASA Glenn Research Center の “Navier–Stokes Equations” をもとに再構成しています。

## Equation

`∂v/∂t + (v·∇)v = −∇p/ρ + ν(∇²)v + F`

`∇·v = 0`

一定密度の非圧縮性ニュートン流体についての標準的なベクトル表記の一つです。
