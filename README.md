# ∂v/∂t

一枚の論文から抜け出した `(v・∇)v`（ナビエ）を指で導き、粘る `ν(∇²)v`（ストークス）が追う、数十秒のタイポグラフィ・ゲームです。

冒頭に説明や開始ボタンはありません。実フォントの数式だけで、文字の森、流れ、粘性、渦、∞までを描きます。最後にのみ、ナビエ–ストークス方程式について短い史実を表示します。

## 操作

- マウスまたは指でナビエを引く
- 流れに沿うと軽く、逆らうと重い
- ストークスを置いていくとナビエも進みにくくなる
- 最後の渦を回ると二つの項が∞へ入る

## 方程式

`∂v/∂t + (v・∇)v = −∇p/ρ + ν(∇²)v + F`, `∇・v = 0`

一定密度の非圧縮性ニュートン流体を表す標準的な書き方の一つです。`F` は単位質量あたりの外力として扱っています。
